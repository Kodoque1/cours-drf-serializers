# Corrigé — réservé au formateur

Ce dossier contient la solution complète de la ressource **miroir**
(`formation/`). Il n'est **pas destiné aux étudiants** — ne pas le
distribuer avec le reste du projet.

Il sert à :
- vérifier que les scripts de tests (`formation/tests/`) sont corrects
  (ils passent tous au vert contre cette solution) ;
- débloquer rapidement un binôme en difficulté sans lui donner directement
  le fichier (montrer un extrait ciblé plutôt que le corrigé entier).

Pour valider : copier `formation_serializers_corrige.py` sur
`formation/serializers.py` et `formation_validators_corrige.py` sur
`formation/validators.py`, puis `python manage.py test formation`.
