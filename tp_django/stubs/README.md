# Stubs (version étudiante)

Sauvegarde de `formation/serializers.py` et `formation/validators.py` tels
qu'ils doivent être distribués aux étudiants (avec les `# TODO TPx`), avant
que `formation/` ne soit rempli avec le corrigé complet.

Pour redonner le projet aux étudiants, restaurer ces deux fichiers :

```bash
cp stubs/formation_serializers_stub.py formation/serializers.py
cp stubs/formation_validators_stub.py formation/validators.py
```
